HELP CENTER

FAQ Potato SMP.

Pertanyaan penting untuk player baru.

01. Apa itu Potato SMP?
Server Minecraft dengan konsep Survival Economy dan gameplay multiplayer.
02. Apa IP server?
IP yang ditampilkan website: potatosmp.fun.
03. Berapa port Bedrock?
Port Bedrock yang ditampilkan: 19132.
04. Bisa main dari HP?
Gunakan Minecraft Bedrock dan masukkan IP serta port Bedrock.
05. Bisa main Java?
Gunakan menu Multiplayer dan masukkan alamat server.
06. Versi apa yang digunakan?
Website menampilkan Java 1.20+ dan Bedrock 1.21+.
07. Apa yang dilakukan setelah masuk?
Mulai survival, kumpulkan resource, bangun tempat tinggal, lalu kembangkan progres.
08. Apakah ada ekonomi?
Ya, website menjelaskan server sebagai Survival Economy.
09. Bagaimana cara mendapatkan uang?
Gunakan aktivitas gameplay dan sistem ekonomi yang tersedia.
10. Apa itu claim?
Sistem perlindungan area; batasnya dapat mengikuti rank.
11. Apa itu SetHome?
Fitur untuk menyimpan lokasi penting.
12. Apa itu Block Limit?
Batas blok yang dapat tercakup dalam perlindungan claim.
13. Apa itu Player Vault?
Penyimpanan tambahan pemain yang dapat mengikuti rank.
14. Ada AFK Zone?
AFK Zone tercantum sebagai salah satu aktivitas server.
15. Ada Mining?
Mining area tercantum untuk aktivitas menambang resource.
16. Ada Farming?
Farming area tercantum untuk bercocok tanam dan memanen.
17. Ada PvP?
PvP Arena tercantum sebagai area pertarungan.
18. Apa itu CPvP?
Mode pertarungan dengan gaya Crystal PvP.
19. Bagaimana cara vote?
Masukkan nickname, pilih platform, lalu buka halaman voting.
20. Format Java saat vote?
Gunakan nickname biasa tanpa titik.
21. Format Bedrock saat vote?
Gunakan titik di depan nickname, misalnya .Nama.
22. Apa reward vote?
Website menampilkan 20K Money, 1× Key Vote, dan Rank Voter + Fly 3 Jam.
23. Wajib beli rank?
Tidak. Rank adalah tambahan dari Store.
24. Di mana melihat rank?
Buka menu Rank untuk melihat benefit dan informasi Store.
25. Java dan Bedrock bisa rank?
Kartu rank dibuat dengan label Java dan Bedrock.
26. Bagaimana upgrade rank?
Pilih rank tujuan dan ikuti informasi upgrade pada Store.
27. Di mana melihat IP?
Di halaman Server atau tombol Salin IP di Beranda.
28. Gagal masuk server, bagaimana?
Cek IP, port, versi Minecraft, dan koneksi internet.
29. Bagaimana meminta bantuan?
Gunakan panduan dan kanal komunitas yang tersedia.
30. Apa perbedaan Java dan Bedrock?
Keduanya merupakan edisi Minecraft berbeda; gunakan cara koneksi sesuai platform.
31. Di mana melihat gamemode?
Buka menu Gamemode untuk melihat aktivitas yang tersedia.
