Pertanyaan tentang Potato SMP

Baru pertama kali masuk? Ini jawaban singkat supaya kamu langsung tahu harus mulai dari mana.

🎮 Apa IP server Potato SMP?

IP server: potatosmp.fun. Untuk Bedrock, gunakan port 19132.

📱 Apakah bisa main dari HP?

Ya. Potato SMP menyediakan akses Bedrock, jadi player mobile dapat bergabung menggunakan alamat server dan port Bedrock.

💻 Bagaimana cara masuk dari Java?

Buka Minecraft Java → Multiplayer → Add Server, lalu masukkan potatosmp.fun dan simpan.

🧭 Setelah masuk server, harus ngapain?

Mulai dari survival, kumpulkan resource, buat tempat tinggal, gunakan fitur ekonomi, dan kenali area server. Kamu juga bisa mengikuti event dan aktivitas komunitas.

💰 Bagaimana cara mendapatkan uang?

Manfaatkan sistem ekonomi dan aktivitas server yang tersedia. Kamu bisa menjual hasil permainan dan mengembangkan balance untuk kebutuhan gameplay.

🏠 Apakah rumah bisa diamankan?

Server menyediakan fitur claim/land protection. Gunakan sistem tersebut untuk membantu melindungi area bangunanmu.

🗳️ Bagaimana cara vote?

Gunakan tombol Vote pada menu untuk menuju halaman voting server dan ikuti petunjuk yang tersedia.

👑 Apakah harus membeli rank?

Tidak. Rank Store adalah tambahan. Kamu tetap dapat bermain dan menikmati gameplay utama tanpa membeli rank.

Panduan Pemula

Mulai dari nol tanpa bingung.

Penjelasan lengkap untuk player yang baru pertama kali masuk Potato SMP.

01

Kenali server

Potato SMP adalah server Minecraft Indonesia dengan konsep Survival Economy. SMP berarti Survival Multiplayer, jadi kamu bermain dan berkembang bersama komunitas.

02

Siapkan Minecraft

Java dapat bergabung menggunakan IP potatosmp.fun. Untuk Bedrock, gunakan IP yang sama dan port 19132. Pastikan versi Minecraft sesuai dengan versi yang didukung server.

03

Masuk dari HP

Buka Minecraft Bedrock → Play → Servers → Add Server. Isi nama server, IP potatosmp.fun, port 19132, lalu simpan dan masuk.

04

Masuk dari PC Java

Buka Multiplayer → Add Server. Masukkan potatosmp.fun, klik Done, kemudian pilih server dan Join Server.

05

Setelah berhasil masuk

Mulai survival, cari resource, buat tempat tinggal, kenali area server, dan manfaatkan sistem ekonomi. Jangan terburu-buru membeli item sebelum memahami gameplay.

06

Kembangkan akun

Gunakan fitur server yang tersedia untuk membantu perkembanganmu. Tujuannya bukan hanya punya item bagus, tetapi membangun progres dan ekonomi yang stabil.

07

Gunakan fitur ekonomi

Server memiliki sistem ekonomi. Kamu bisa memanfaatkan aktivitas gameplay dan fitur jual-beli untuk mengembangkan balance dan memenuhi kebutuhan permainan.

08

Lindungi bangunan

Gunakan sistem perlindungan/claim yang tersedia untuk membantu menjaga area bangunanmu. Sebelum membangun besar, pahami dulu aturan perlindungan area server.

09

Ikuti vote & event

Vote dapat memberikan reward server. Event juga menjadi cara untuk ikut aktivitas komunitas dan mendapatkan pengalaman bermain yang lebih ramai.

10

Butuh bantuan?

Gunakan tombol Discord, WhatsApp, atau menu bantuan di website. Simpan IP server agar mudah kembali bermain kapan saja.

💡 Tips penting untuk pemula

Jangan memberikan password atau data akun kepada orang lain. Baca aturan server sebelum melakukan transaksi atau aktivitas yang berisiko merugikan akunmu.
