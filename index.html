HELP CENTER

Pertanyaan lengkap tentang server.

31 jawaban untuk membantu player baru memahami Potato SMP.

01. Apa itu Potato SMP?
Potato SMP adalah server Minecraft Indonesia dengan konsep Survival Economy. Fokusnya survival, perkembangan pemain, dan ekonomi bersama komunitas.
02. Apa arti SMP?
SMP adalah singkatan dari Survival Multiplayer, yaitu permainan survival yang dimainkan bersama pemain lain.
03. Apa IP server?
IP yang ditampilkan pada website adalah potatosmp.fun.
04. Berapa port Bedrock?
Port Bedrock yang ditampilkan pada website adalah 19132.
05. Versi apa yang ditampilkan?
Website saat ini menampilkan Java 1.20+ dan Bedrock 1.21+. Jika admin mengubah versi, ikuti informasi terbaru server.
06. Bisa main dari HP?
Jika memakai Minecraft Bedrock, gunakan IP server dan port Bedrock yang tercantum pada halaman Server.
07. Bisa main dari Java?
Ya. Masuk ke Multiplayer → Add Server, lalu masukkan alamat server yang tercantum.
08. Apa yang dilakukan setelah masuk?
Mulai survival, kumpulkan resource, buat tempat tinggal, kenali area server, lalu kembangkan progres melalui gameplay dan ekonomi.
09. Apakah ada sistem ekonomi?
Ada. Website menjelaskan Potato SMP sebagai server Survival Economy.
10. Bagaimana cara mendapatkan uang?
Manfaatkan aktivitas gameplay dan sistem ekonomi yang tersedia. Metode jual-beli spesifik sebaiknya mengikuti fitur yang aktif di server.
11. Apa itu claim?
Claim adalah sistem perlindungan area. Data Store mencantumkan Claim Limit pada rank, sehingga batasnya dapat berbeda.
12. Apa itu SetHome?
SetHome digunakan untuk menyimpan lokasi penting. Jumlah SetHome berbeda pada beberapa rank di Store.
13. Apa itu Block Limit?
Block Limit adalah batas blok dalam perlindungan claim. Batasnya berbeda menurut rank.
14. Apa itu Player Vault?
Player Vault adalah penyimpanan tambahan pemain. Jumlahnya mengikuti rank yang dimiliki.
15. Apakah ada AFK Zone?
Data gamemode pada website menyebut AFK Zone sebagai area untuk bersantai dan mendapatkan reward otomatis saat tidak aktif.
16. Apakah ada area mining?
Data gamemode menyebut Mining Sim sebagai area untuk menambang sumber daya berharga.
17. Apakah ada farming?
Data gamemode menyebut Farming Area sebagai area bercocok tanam dan memanen.
18. Apakah ada PvP?
Data gamemode menyebut PvP Arena sebagai arena pertarungan antar pemain.
19. Apa itu CPvP?
Data gamemode menyebut CPvP Fight sebagai mode pertarungan menggunakan Crystal PvP.
20. Bagaimana cara vote?
Buka menu Vote, masukkan nickname Minecraft, pilih platform, lalu lanjutkan ke halaman voting server.
21. Apa format nickname Java saat vote?
Pada panduan vote di file, Java menggunakan nickname biasa tanpa titik.
22. Apa format nickname Bedrock saat vote?
Pada panduan vote di file, Bedrock menggunakan titik di depan nickname, misalnya .Kentang6814.
23. Apakah vote punya reward?
Website mencantumkan reward vote. Karena reward bisa berubah, halaman Vote menjadi acuan yang ditampilkan saat ini.
24. Apakah wajib membeli rank?
Tidak. Rank adalah tambahan dari Store; gameplay utama tidak dijelaskan sebagai wajib membeli rank.
25. Bagaimana cara membeli rank?
Pilih rank di Store lalu gunakan tombol pembelian untuk menghubungi admin. Website meminta nickname, platform, dan durasi.
26. Apa itu upgrade rank?
Upgrade rank menggunakan selisih harga rank tujuan dengan rank yang sedang dimiliki, sesuai contoh pada Store.
27. Java dan Bedrock bisa menggunakan rank?
Kartu rank pada website diberi label Java dan Bedrock. Benefit mengikuti daftar pada masing-masing rank.
28. Di mana melihat rank?
Buka menu Rank/Store untuk melihat harga, durasi, dan benefit yang tercantum.
29. Di mana melihat IP dan port?
Buka menu Server. Di sana IP, port Bedrock, dan versi ditampilkan bersama.
30. Apa yang dilakukan kalau gagal masuk?
Periksa IP, port, versi Minecraft, dan koneksi internet. Jika masih gagal, gunakan kanal komunitas/admin yang tersedia.
31. Bagaimana cara mendapatkan bantuan?
Baca Panduan dan FAQ terlebih dahulu. Jika belum terjawab, gunakan kanal komunitas yang dicantumkan website.
